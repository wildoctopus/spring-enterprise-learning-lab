# Code of Conduct

## Our standard

We want this to be a useful, respectful learning community for Java and backend
engineers at every experience level. Participate with patience, curiosity, and
respect for different backgrounds, communication styles, and technical viewpoints.

Constructive disagreement is welcome. Personal attacks, harassment, discrimination,
doxxing, sexualized conduct, threats, and deliberately disruptive behavior are not.
Do not share confidential information or proprietary interview material.

## Enforcement

Project maintainers may edit, remove, or decline contributions that violate this
standard and may limit participation when necessary to protect the community.

Report concerns privately to the repository maintainers through the contact method
listed in the repository profile. Please include links or screenshots and a concise
description of what happened. We will handle reports as confidentially as practical.
